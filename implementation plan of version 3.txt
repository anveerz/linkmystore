Here's a quick summary of the 5 phases:

Phase 1 — Free vs Pro Plans (₹199/mo): Foundation for everything. New subscriptions table, plan-gating utility, Razorpay subscription billing, feature limits (5 products free, unlimited pro), branding control, analytics tiers.

Phase 2 — UPI Direct Payments: Replace Razorpay for product purchases with direct UPI deep links (upi://pay?pa=...). Buyer enters UPI reference number or uploads screenshot. Seller manually verifies. Platform never touches money.

Phase 3 — Revised Onboarding: Expand from 2 steps to 5 (store setup → category/bio → UPI ID → first product → policies/go live). Collect only name, phone, UPI ID — no PAN/GST/bank account.

Phase 4 — Affiliate Store: Sellers paste Amazon/Flipkart URLs → system auto-injects affiliate tags with sub-tracking. Commission split: 50/50 free, 100% pro. Click tracking, earnings dashboard, monthly payouts.

Phase 5 — WhatsApp Notifications: Pro-only order notifications via WhatsApp Business API or third-party service.

Claude’s Plan
LinkMyStore — Business Model Implementation Plan
Context
The LinkMyStore platform is a mature Next.js app (Supabase + Razorpay + TailwindCSS) that already has: auth, product management (physical + 8 digital subtypes), storefront, Razorpay checkout, orders, dashboard, analytics, coupons, bookings, courses, reviews, Instagram automation, and payouts.

The business model document introduces 4 major new capabilities that transform LinkMyStore from a single-tier platform into a freemium business with direct UPI payments and affiliate monetization. This plan implements them in dependency order.

2.2 UPI Deep Link Generation
New file: lib/upi.ts


export function generateUPILink(params: {
  payeeVPA: string;       // seller's UPI ID
  payeeName: string;      // seller's store name
  amount: number;         // in rupees (not paisa)
  transactionNote: string; // "Order-LMS-XXXX"
  currency?: string;
}): string {
  return `upi://pay?pa=${encodeURIComponent(params.payeeVPA)}&pn=${encodeURIComponent(params.payeeName)}&am=${params.amount}&cu=${params.currency || 'INR'}&tn=${encodeURIComponent(params.transactionNote)}`
}
