# PureJawari

Standalone product landing page for the `PureJawari` flour brand.

## What's included

- `purejawari.html`: the full responsive webpage
- `assets/images/*.svg`: placeholder images you can replace later with your real photos

## Current product sections

- Jowar (Sorghum)
- Wheat
- Maize (Corn)
- Ragi

## Pack sizes

- 1 kg
- 2 kg
- 3 kg
- 5 kg
- 10 kg

## Replace the placeholder images

Keep the same filenames if you want the page to update automatically.

Examples:

- `assets/images/01-jowar-field.svg`
- `assets/images/04-jowar-rotti.svg`
- `assets/images/09-chapati.svg`
- `assets/images/11-maize-grains.svg`
- `assets/images/12-ragi-grains.svg`

You can replace these SVG files with your own `.jpg`, `.png`, `.webp`, or `.svg` images if you also update the file paths inside `purejawari.html`.

## Open locally

Open `purejawari.html` in any browser.
